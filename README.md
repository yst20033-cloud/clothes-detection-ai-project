# Clothes Detection AI Project

## Project Description
This project implements an AI-based clothes detection system using deep learning. The model is trained to detect and identify clothing items from images. The entire project is developed and executed using Google Colab.

This project was completed as part of an academic assignment and is designed to be simple and reproducible, even for users without a computer science background.

---

## Environment Setup and Requirements
This project runs **only on Google Colab**.

Required tools:
- Google Colab (web-based)
- Python (pre-installed in Colab)
- Common libraries such as:
  - TensorFlow / PyTorch
  - OpenCV
  - NumPy
  - Matplotlib

All required libraries are installed directly inside the Colab notebook.

---

## How to Run the Project (Reproduce Results)

1. Open the uploaded `.ipynb` file in this repository.
2. Click **Open in Colab** (top of the notebook).
3. In Colab, select **Runtime → Run all**.
4. The notebook will automatically:
   - Install required libraries
   - Load the dataset (via links)
   - Train the model
   - Display detection results

---

## Training Your Own Model

To train the model again:
1. Open the notebook in Google Colab.
2. Run all cells from top to bottom.
3. Modify training parameters such as epochs or learning rate if needed.
4. The model will retrain and show updated results.

---

## Results Summary
The model is able to detect clothing items from images and display bounding boxes with predicted labels. Sample outputs and evaluation results are shown directly in the notebook.

---

## Notes and Limitations
- The project runs **only on Google Colab**.
- Large datasets are not uploaded to GitHub due to size limitations.
- Model performance depends on dataset quality and training time.
